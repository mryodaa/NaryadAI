# Использованные AI-инструменты

По положению хакатона указываем AI-инструменты, которые использовались в разработке.

| Инструмент | Для чего |
|---|---|
| **Claude Code** (Anthropic, модель Claude Opus) | Совместная разработка: план работ по этапам, каркас монорепо, контракты и схемы, шлюз, имитаторы, ядро двойника, тесты, интерфейс, документация. Самопроверка вёрстки скриншотами на 1366×768 и 1920×1080 (Playwright) |

## Как мы работали

- Требования, принципы интерфейса и приоритеты задавала команда (раздел «Задание» и отчёты после каждого этапа). Решения по спорным местам принимала команда: например, допущение о рабочих субботах для плана 5 500.
- Код написан с участием Claude Code, разобран и проверен командой. Ключевая логика — правила статусов, показатели, прогноз, причины брака — покрыта тестами (`pnpm test`) и объяснима: у каждого вычисления есть «Почему?» с входными данными и источниками.
- В самом продукте внешние AI-сервисы не используются. Прогнозы и рекомендации строятся на правилах, статистике и симуляции (Монте-Карло), без «чёрного ящика» и без обязательных API-ключей. Модели машинного обучения предлагается дообучать на истории завода в ходе пилота.
