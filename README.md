# NaryadAI — цифровой двойник завода (демо)

Фронтенд-прототип для хакатона: в браузере работает симулятор автомобильной линии, а поверх него — аналитика и «ИИ».
Бэкенда, API и обученных моделей нет: всё считается на клиенте, чтобы показать, **как работает каждая идея**.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
```

## Что показывает демо

| Экран | Идея |
|---|---|
| **Цех** | Живая схема линии: участки, буферы, оборудование. Слои «Статус / Цена простоя / Риск ИИ». **Машина времени**: ползунок влево — история, вправо — прогноз состояния завода |
| **Директор** | Брифинг от ИИ, ассистент с вопросами, решения, отсортированные по деньгам под риском, динамическая цена простоя |
| **Механик** | Замкнутый цикл «сигнал → наряд → работа → обратная связь → дообучение», мобильный экран нарядов |
| **Журналы** | «ИИ» разбирает свободный текст из журналов операторов в структуру (участок, причина, длительность) |
| **Сравнить решения** | What-if: каждый вариант («ТО сейчас / в пересменку / ничего не делать») — отдельный прогон двойника вперёд |

## Сценарий демонстрации (≈3 минуты)

1. **Сценарии → «Износ подшипника пресса П-2»**, скорость 20×. На схеме включить слой «Риск ИИ».
2. Риск П-2 растёт, ИИ создаёт инцидент и наряд. Кликнуть точку P-2: график вибрации с трендом и объяснение «почему ИИ так считает».
3. **«Сравнить решения»**: ТО сейчас ≈ 45 тыс ₽ (буферы поглощают остановку) против ~18 млн ₽ при бездействии.
4. **Утвердить** → вкладка **Механик**: наряд в работе → «Неисправность подтвердилась» → растёт «Предотвращено благодаря ИИ».
5. Ползунок машины времени вправо: на схеме прогноз состояния завода, ромб на шкале — прогноз отказа.
6. **Сценарии → «Задержка поставки»**: двойник считает, когда встанет сборка и сколько это стоит, кнопка экстренной поставки.

## Структура

```
src/sim/        ядро: модель завода и логика (без React)
  config.ts       участки, оборудование, экономика, пороги
  engine.ts       шаг симуляции (1 мин), отказы, инциденты, наряды, сценарии
  analytics.ts    KPI/OEE, узкое место, динамическая цена простоя
  model.ts        «ИИ» прогноза отказов: логистическая модель + вклад признаков
  forecast.ts     прогноз (прогон копии двойника) и what-if
  assistant.ts    шаблонный эмулятор LLM: брифинг и ответы
  journal.ts      эмулятор LLM-разбора журналов
src/components/ схема завода, машина времени, графики, панели
src/views/      экраны ролей
```

## Что заменить в настоящем MVP

- `engine.ts` → поток реальных событий (MES/SCADA/OPC UA, Kafka/MQTT) + бэкенд с WebSocket.
- `model.ts` → обученная модель (CatBoost/LightGBM на истории отказов) + SHAP для объяснений; интерфейс тот же: вероятность + вклады признаков.
- `assistant.ts`, `journal.ts` → вызовы LLM с tool use / JSON-схемой ответа.
- What-if и прогноз уже устроены как «прогон копии двойника» — в продакшене это SimPy-модель на сервере.

Все данные в демо синтетические.
